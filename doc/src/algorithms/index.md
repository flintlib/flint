---
title: Algorithms
summary: How FLINT computes what it computes, from single machine words to threads.
---

Function documentation says *what* a function computes. This part of the
documentation says *how*. Overview pages compare the methods FLINT uses for one task and say
which functions use which; algorithm pages state a single method precisely,
prove it correct where the proof fits on a page, and give references to the
literature. Every algorithm page lists the functions and pages that refer to
it.
