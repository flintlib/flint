This module implements operations on vectors of integers. A vector is a
plain array of `fmpz` together with a length, written `(vec, len)`. It is
the coefficient array of `fmpz_poly` and the row storage of `fmpz_mat`.
The functions, all with a leading underscore, leave memory management to
the caller. The module also has a small resizable vector type, `fmpz_vec_t`.
See [](fmpz/getting-started#arrays) for how to work with arrays of
integers, and [](fmpz_vec/dot) for dot products.

## Conventions {#conventions}

- A vector `(vec, len)` is an array of at least `len` initialised `fmpz`.
  A length of zero is allowed unless stated otherwise.
- Functions with an output vector allow it to be the same array as an
  input vector (exact aliasing), but not a partial overlap. A scalar
  output such as `res` in `_fmpz_vec_sum` must not be an entry of an
  input vector.
- As for `fmpz`, division by zero raises an exception, and exact
  divisions are not checked.

## Memory management {#memory}

::: function
fmpz * _fmpz_vec_init(slong len)

Returns an array of `len` integers, all zero, allocated with
`flint_calloc` (an `fmpz` with value zero is a zero word).
:::

::: function
void _fmpz_vec_clear(fmpz * vec, slong len)

Clears the `len` entries of `vec` and frees the array.
:::

::: macro
FMPZ_VEC_TMP_INIT(vec, len)
FMPZ_VEC_TMP_CLEAR(vec, len)

Allocate a temporary vector of `len` initialised integers with
`TMP_ALLOC` and assign it to `vec`, respectively clear its entries. Use
between `TMP_START` and `TMP_END`.
:::

::: macro
FMPZ_VEC_NORM(vec, i)

Decreases the variable `i` while `vec[i - 1]` is zero, that is, strips
zero entries from the end of a vector of length `i`. Used to normalise
polynomial lengths.
:::

::: macro
FMPZ_VEC_SWAP(vec1, len1, vec2, len2)

Swaps the pointers `vec1` and `vec2` and the lengths `len1` and `len2`.
:::

## Resizable vectors {#resizable}

::: type
fmpz_vec_struct
fmpz_vec_t

A vector that manages its own memory, with fields `entries` (an array
of `alloc` initialised integers, of which the first `length` are in
use), `alloc` and `length`. Entries from `length` to `alloc - 1` are
always zero.
:::

::: function
void fmpz_vec_init(fmpz_vec_t vec, slong len)
void fmpz_vec_clear(fmpz_vec_t vec)

Initialise `vec` to a vector of length `len` with all entries zero,
respectively release its memory.
:::

::: function
slong fmpz_vec_length(const fmpz_vec_t vec)

Returns the length of `vec`.
:::

::: function
fmpz * fmpz_vec_entry_ptr(fmpz_vec_t vec, slong i)
const fmpz * fmpz_vec_entry_srcptr(const fmpz_vec_t vec, slong i)

Return a pointer to entry $i$, which can be used as an `fmpz_t`. The
index is not checked.
:::

::: function
void fmpz_vec_fit_length(fmpz_vec_t vec, slong len)

Ensures that `vec` has room for at least `len` entries, at least doubling
the allocation when it grows. The length is not changed.
:::

::: function
void fmpz_vec_set_length(fmpz_vec_t vec, slong len)

Sets the length to `len` $\ge 0$. Entries beyond a smaller new length are
set to zero (releasing their memory); entries added by a larger new
length are zero.
:::

::: function
void fmpz_vec_set(fmpz_vec_t res, const fmpz_vec_t src)

Sets `res` to a copy of `src`.
:::

::: function
void fmpz_vec_append(fmpz_vec_t vec, const fmpz_t f)
void fmpz_vec_append_ui(fmpz_vec_t vec, ulong f)

Append $f$ to `vec`, increasing its length by one.
:::

## Random vectors {#random}

::: function
void _fmpz_vec_randtest(fmpz * f, flint_rand_t state, slong len, flint_bitcnt_t bits)
void _fmpz_vec_randtest_unsigned(fmpz * f, flint_rand_t state, slong len, flint_bitcnt_t bits)

Set the entries to random integers of at most `bits` bits, generated by
`fmpz_randtest` (respectively `fmpz_randtest_unsigned`). With
probability 1/2 the vector is made sparse, with a random proportion of
zero entries, to exercise special cases in tests.
:::

## Bit sizes and norms {#norms}

::: function
slong _fmpz_vec_max_bits(const fmpz * vec, slong len)
slong _fmpz_vec_max_bits_ref(const fmpz * vec, slong len)

Return $b$ or $-b$, where $b$ is the maximum of the bit sizes of the
absolute values of the entries; the sign is negative if some entry is
negative. The `_ref` version is a simple reference implementation used
in tests.
:::

::: function
slong _fmpz_vec_weight_bits(const fmpz * vec, slong len)

Returns the sum of the bit sizes `fmpz_bits` of the entries.
:::

::: function
void _fmpz_vec_sum_max_bits(slong * sumabs, slong * maxabs, const fmpz * vec, slong len)

Sets `*sumabs` to the bit size of the sum of the absolute values of the
entries, and `*maxabs` to the bit size of the largest absolute value.
:::

::: function
slong _fmpz_vec_max_limbs(const fmpz * vec, slong len)

Returns the maximum number of limbs of the absolute values of the entries,
and 0 if all entries are zero.
:::

::: function
void _fmpz_vec_height(fmpz_t height, const fmpz * vec, slong len)
slong _fmpz_vec_height_index(const fmpz * vec, slong len)

`_fmpz_vec_height` sets `height` to the largest absolute value of an
entry (the $\ell^\infty$ norm), which is 0 for `len` $= 0$.
`_fmpz_vec_height_index` returns the index of an entry of largest
absolute value and requires `len` $\ge 1$.
:::

## Input and output {#io}

::: function
int _fmpz_vec_fprint(FILE * file, const fmpz * vec, slong len)
int _fmpz_vec_print(const fmpz * vec, slong len)

Print the vector to `file` or `stdout` as the length, two spaces and the
entries separated by single spaces; a vector of length zero is printed
as `0`. Return a positive value on success and a nonpositive value on
failure.
:::

::: function
int _fmpz_vec_fread(FILE * file, fmpz ** vec, slong * len)
int _fmpz_vec_read(fmpz ** vec, slong * len)

Read a vector in the format of `_fmpz_vec_fprint` from `file` or
`stdin`. Return a positive value on success and a nonpositive value on
failure.

::: details
If `*vec` is `NULL`, the length is read from the stream, a vector of
that length is allocated and assigned to `*vec`, and `*len` is set. On
failure the vector is cleared and `*vec` and `*len` are set to `NULL` and
0.

If `*vec` is not `NULL`, `(*vec, *len)` must be an initialised vector,
and the length read must equal `*len`; otherwise a parsing error is
reported. On failure the vector is left in its current state, which may
be partially overwritten.
:::
:::

## Conversions {#conversions}

::: function
void _fmpz_vec_get_nmod_vec(nn_ptr res, const fmpz * poly, slong len, nmod_t mod)

Sets `res[i]` to the residue in $[0, n)$ of `poly[i]` modulo the modulus
$n$ of `mod`.
:::

::: function
void _fmpz_vec_set_nmod_vec(fmpz * res, nn_srcptr poly, slong len, nmod_t mod)

Sets `res[i]` to the symmetric representative in $(-n/2, n/2]$ of the
reduced residue `poly[i]` modulo $n$.
:::

::: function
slong _fmpz_vec_get_d_vec_2exp(double * appv, const fmpz * vec, slong len)

Returns an exponent $e$ and sets `appv[i]` to doubles with
`appv[i]`$\cdot 2^e \approx$ `vec[i]`, where $e$ is the largest exponent
of `fmpz_get_d_2exp` over the entries, so that all `appv[i]` have
absolute value less than 1. Entries much smaller than the largest lose
precision or become 0.
:::

::: function
void _fmpz_vec_get_fft(ulong ** coeffs_f, const fmpz * coeffs_m, slong l, slong length)
void _fmpz_vec_set_fft(fmpz * coeffs_m, slong length, const nn_ptr * coeffs_f, slong limbs, slong sign)

Convert between a vector of integers and the coefficient arrays of the
Schönhage–Strassen FFT of the [`fft`](fft) module, used by
`fmpz_poly_mul_SS`. `_fmpz_vec_get_fft` writes each of the `length`
entries to `coeffs_f[i]` as $l$ limbs plus one limb for overflow,
negative values in two's complement over the $l + 1$ limbs (the entries
must fit in $l$ limbs). The conversion is done in parallel when threads
are available.
`_fmpz_vec_set_fft` converts fully reduced residues of `limbs` limbs
back, to the range $[-N, N]$ with $N = 2^{\bits \cdot \mathit{limbs} -
1}$ if `sign` is nonzero and to $[0, 2N]$ otherwise.
:::

void _fmpz_vec_scalar_addmul_si(fmpz * vec1, const fmpz * vec2, slong len2, slong c)
void _fmpz_vec_scalar_addmul_ui(fmpz * vec1, const fmpz * vec2, slong len2, ulong c)

:::

::: function
void _fmpz_vec_scalar_addmul_si_2exp(fmpz * vec1, const fmpz * vec2, slong len2, slong c, ulong exp)
void _fmpz_vec_scalar_submul_si_2exp(fmpz * vec1, const fmpz * vec2, slong len2, slong c, ulong exp)

Add (respectively subtract) `vec2` multiplied by $c 2^{\mathit{exp}}$ to
(from) `vec1`.
:::

::: function
void _fmpz_vec_scalar_divexact_fmpz(fmpz * vec1, const fmpz * vec2, slong len2, const fmpz_t x)
void _fmpz_vec_scalar_divexact_si(fmpz * vec1, const fmpz * vec2, slong len2, slong c)
void _fmpz_vec_scalar_divexact_ui(fmpz * vec1, const fmpz * vec2, slong len2, ulong c)

Set `vec1` to `vec2` divided by the nonzero scalar, assuming that every
division is exact (not checked).

::: details
For a multi-limb $x$ and at least two entries as large as $x$,
`_fmpz_vec_scalar_divexact_fmpz` computes a 2-adic inverse of the odd
part of $x$ once, only to the precision of the largest quotient, and
uses it for all entries (`flint_mpn_divexact_preinv`), which saves the
Newton iteration of each separate exact division
([](algorithms/integers/division#hensel)).
:::
:::

::: function
void _fmpz_vec_scalar_divexact_fmpz_strided(fmpz * B, slong Bstride, const fmpz * A, slong Astride, slong r, slong c, const fmpz_t x)

Sets the $r \times c$ array `B` to `A` divided exactly by $x$, where row
$i$ of `B` (respectively `A`) is the $c$ entries starting at
`B + i * Bstride` (`A + i * Astride`). Exactness is not checked. In-place
operation is allowed with `B = A` and `Bstride = Astride`.

::: details
Equivalent to `_fmpz_vec_scalar_divexact_fmpz` on each row, but for a
multi-limb $x$ a single inverse, to the precision of the largest quotient
in the whole array, is shared by all rows. Used by
`fmpz_mat_scalar_divexact_fmpz`.
:::
:::

::: function
void _fmpz_vec_scalar_fdiv_q_fmpz(fmpz * vec1, const fmpz * vec2, slong len2, const fmpz_t c)
void _fmpz_vec_scalar_fdiv_q_si(fmpz * vec1, const fmpz * vec2, slong len2, slong c)
void _fmpz_vec_scalar_fdiv_q_ui(fmpz * vec1, const fmpz * vec2, slong len2, ulong c)
void _fmpz_vec_scalar_tdiv_q_fmpz(fmpz * vec1, const fmpz * vec2, slong len2, const fmpz_t c)
void _fmpz_vec_scalar_tdiv_q_si(fmpz * vec1, const fmpz * vec2, slong len2, slong c)
void _fmpz_vec_scalar_tdiv_q_ui(fmpz * vec1, const fmpz * vec2, slong len2, ulong c)

Set `vec1` to the quotients of the entries of `vec2` by $c \ne 0$,
rounded towards $-\infty$ (`fdiv`) or towards zero (`tdiv`); see
[](fmpz/division).
:::

::: function
void _fmpz_vec_scalar_fdiv_q_2exp(fmpz * vec1, const fmpz * vec2, slong len2, ulong exp)
void _fmpz_vec_scalar_tdiv_q_2exp(fmpz * vec1, const fmpz * vec2, slong len2, ulong exp)
void _fmpz_vec_scalar_fdiv_r_2exp(fmpz * vec1, const fmpz * vec2, slong len2, ulong exp)

Set `vec1` to the quotients of the entries by $2^{\mathit{exp}}$, rounded
towards $-\infty$ or towards zero, respectively to the remainders of
floor division, which lie in $[0, 2^{\mathit{exp}})$.
:::

## Reduction and Chinese remaindering {#modular}

::: function
void _fmpz_vec_scalar_mod_fmpz(fmpz * res, const fmpz * vec, slong len, const fmpz_t p)
void _fmpz_vec_scalar_smod_fmpz(fmpz * res, const fmpz * vec, slong len, const fmpz_t p)

Reduce the entries modulo $p > 0$, to $[0, p)$, respectively to the
symmetric range $(-p/2, p/2]$.
:::

::: function
void _fmpz_vec_multi_CRT_ui(fmpz * res, nn_srcptr * residues, slong len, nn_srcptr primes, slong num_primes, int sign)

Sets `res[j]` for $0 \le j <$ `len` to the integer congruent to
`residues[i][j]` modulo `primes[i]` for all $0 \le i <$ `num_primes`, in
$[0, M)$ if `sign` is 0 and in $(-M/2, M/2]$ otherwise, where $M$ is the
product of the pairwise coprime word-size moduli. The precomputation is
shared by all entries; each entry is reconstructed as by
`fmpz_multi_CRT_ui` ([](fmpz/crt)).
:::

## Sums, products and content {#sums}

::: function
void _fmpz_vec_sum(fmpz_t res, const fmpz * vec, slong len)

Sets `res` to the sum of the entries.
:::

::: function
void _fmpz_vec_prod(fmpz_t res, const fmpz * vec, slong len)
void _fmpz_ui_vec_prod(fmpz_t res, nn_srcptr vec, slong len)

Set `res` to the product of the entries of an array of integers,
respectively of words; the empty product is 1. Both use a balanced
product tree ([](algorithms/integers/binary-splitting)), with leaves of
at most 3 integers, respectively 15 words, multiplied in sequence.
:::

::: function
void _fmpz_vec_content(fmpz_t res, const fmpz * vec, slong len)
void _fmpz_vec_content_chained(fmpz_t res, const fmpz * vec, slong len, const fmpz_t inp)

Set `res` to the nonnegative GCD of the entries (0 for a zero or empty
vector), respectively of the entries and `inp`, which allows the common
content of several vectors to be accumulated; `res` may be aliased with
`inp` or with an entry. The computation stops as soon as the GCD becomes
1. See [](algorithms/integers/gcd#content) for the algorithm.
:::

::: function
void _fmpz_vec_lcm(fmpz_t res, const fmpz * vec, slong len)
void _fmpz_vec_lcm_strided(fmpz_t res, const fmpz * vec, slong stride, slong len, const fmpz_t inp)

Sets `res` to the nonnegative least common multiple of the entries: 0 if
an entry is zero and 1 for an empty vector. The strided version takes the
`len` entries `vec[0]`, `vec[stride]`, ..., and the LCM also with `inp`
unless it is `NULL`, which allows LCMs to be accumulated. `res` may be
aliased with `inp` or with an entry. For an `fmpq` vector `a`, the
denominators are the entries of stride 2 from `fmpq_denref(a)`. See
[](algorithms/integers/gcd#content) for the algorithm.
:::

## Dot products {#dot}

::: function
void _fmpz_vec_dot_general(fmpz_t res, const fmpz_t initial, int subtract, const fmpz * a, const fmpz * b, int reverse, slong len)
void _fmpz_vec_dot_general_naive(fmpz_t res, const fmpz_t initial, int subtract, const fmpz * a, const fmpz * b, int reverse, slong len)

Set `res` to $s + (-1)^{\mathit{subtract}} \sum_{i=0}^{\mathit{len}-1}
a_i b_i$, where $s$ is `initial` (or 0 if `initial` is `NULL`),
`subtract` is 0 or 1, and $b$ is read in reverse order ($b_{len-1-i}$ in
place of $b_i$) if `reverse` is 1. `res` may alias `initial` but not an
entry of `a` or `b`. The `_naive` version is a loop of `fmpz_addmul` used
in tests.
:::

::: function
void _fmpz_vec_dot(fmpz_t res, const fmpz * vec1, const fmpz * vec2, slong len2)

Sets `res` to $\sum_i$ `vec1[i] vec2[i]`; equivalent to
`_fmpz_vec_dot_general(res, NULL, 0, vec1, vec2, 0, len2)`.
:::
