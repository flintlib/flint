title: User guide
summary: Installing and using FLINT: building, conventions, correctness and its limits, types and mathematical domains, ball arithmetic, generic programming, interfaces, and how to contribute.
---

The user guide explains how to install FLINT, how to compile programs
against it, and conventions that all modules share: word types,
naming of functions, aliasing, memory management, multithreading,
portability, error handling, and generic programming.

The guide then explains what FLINT guarantees and what it does not: which
algorithms are proved correct, how FLINT is tested, which inputs are
checked, and limitations. It helps choose among FLINT's many
types for a task and explains rigorous ball arithmetic. It also
describes interfaces to other languages and explains how to report bugs
and contribute.

New users should start with [](guide/getting-started/introduction) and
[](guide/getting-started/building), and then follow the first tutorial,
[](tutorials/getting-started/first-program). The release notes of all
versions are in [](history).
