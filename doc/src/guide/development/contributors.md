FLINT has only been possible thanks to high-quality contributions from a
large number of people since 2007. The file `AUTHORS` in the source tree
lists the authors with their main contributions, and the website keeps
the complete list at https://flintlib.org/authors.html. GitHub shows the
committers at https://github.com/flintlib/flint/graphs/contributors.
The contributors to each release since FLINT 3.0 are named in the
release notes, [](history).

FLINT was started in 2007 by William Hart and David Harvey. William Hart
led the project until 2022. Fredrik Johansson is the current project
leader, and maintains FLINT together with Albin Ahlbäck. The authors with
the largest contributions include William Hart (integer and polynomial
arithmetic, factorisation and primality testing, the Schönhage–Strassen
FFT, number fields), Fredrik Johansson (matrices, polynomials and power
series, special functions, ball arithmetic, floating-point arithmetic,
algebraic and exact real and complex numbers, generic rings), Daniel
Schultz (multivariate polynomials, the thread pool, the small-prime FFT,
LLL), Sebastian Pancratz (polynomials over $\Z$, $\Z/n\Z$ and $\Q$,
$p$-adic numbers, the design of FLINT 2), Andy Novocin (LLL and
factorisation over $\Z$), Mike Hansen (finite fields) and Albin Ahlbäck
(the Autotools build system, assembly code for integer multiplication,
infrastructure and maintenance).

Contributions to FLINT have been supported by research grants, listed in
`AUTHORS`, and by the institutions of the authors.

If you believe that your name is missing from the lists, or that some
information is wrong, please write to the `flint-devel` mailing list.
The lists are updated at each release.
