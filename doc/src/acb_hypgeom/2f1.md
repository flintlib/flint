---
title: The Gauss hypergeometric function
functions: acb_hypgeom_2f1
---

`acb_hypgeom_2f1` computes the Gauss hypergeometric function
${}_2F_1(a,b,c,z)$, or the regularized function $\mathbf{F}(a,b,c,z) =
{}_2F_1(a,b,c,z)/\Gamma(c)$ if the flag `ACB_HYPGEOM_2F1_REGULARIZED` is
set, for all complex $a, b, c, z$, with the branch cut $[1, +\infty)$.
`arb_hypgeom_2f1` is the real version and accepts the same flags. The
series converges only for $|z| < 1$, and slowly near $|z| = 1$; the
function covers the plane with five linear fractional transformations,
evaluates the limits of these formulas at integer parameter
differences, continues analytically along a path near the two points
$e^{\pm\pi i/3}$ that no transformation reaches, and chooses among
these formulas, with the working precision that each requires, and
numerical integration by estimates of their costs. The algorithms are described
in [](algorithms/special-functions/gauss-2f1).

::: summary algorithms/special-functions/gauss-2f1 :::

## Algorithm selection {#selection}

1. Non-finite input gives an indeterminate result; $z = 0$ gives 1 (or
   $1/\Gamma(c)$).
2. For $\mathbf{F}$ with a nonpositive integer $c$, the result is 0 if
   $a$ or $b$ is a nonpositive integer at least $c$ (the series
   terminates before the poles). If $a = c$ or $b = c$, the regularized
   function is $(1-z)^{-b}/\Gamma(c)$ or $(1-z)^{-a}/\Gamma(c)$.
3. If $a$ or $b$ is a nonpositive integer $-n$ with $n <
   \mathit{prec}$, the function is a polynomial of degree $n$, summed
   directly for any $z$.
4. If $c$ is exact and $c - b$ (or $c - a$) is a nonpositive integer,
   the Pfaff transformation $F(a,b,c,z) = (1-z)^{-a} F(a, c-b, c,
   z/(z-1))$ turns the function into a polynomial. The terms of the
   polynomials of steps 3 and 4 can cancel (for $z < 0$ in step 4): if
   the result is not accurate and the input is exact, it is computed
   again with more precision, or by numerical integration, whichever
   is estimated to cost less; with exact parameters and an inexact
   $z$, by its Taylor expansion at the midpoint of $z$; with inexact
   parameters, at the midpoints with a bound for the variation, or by
   integration.
5. At $z = 1$, Gauss's formula $\Gamma(c)\Gamma(c-a-b)/(\Gamma(c-a)
   \Gamma(c-b))$ is used if $\operatorname{Re}(c-a-b) > 0$; otherwise
   the result is indeterminate.
6. For small parameters, `acb_hypgeom_2f1_choose` selects direct
   summation, one of the transformations $z/(z-1)$, $1/z$, $1/(1-z)$,
   $1-z$, $1-1/z$ of `acb_hypgeom_2f1_transform`, or the corner case
   `acb_hypgeom_2f1_corner`, by minimizing the modulus of the new
   argument (direct summation is preferred for $|z| \le 1/4$). This
   is done for parameters up to 30 in absolute value if the series at
   $z$ or $z/(z-1)$ is selected, and for parameters up to 12 if a
   connection formula with an argument of at most $1/2$ is selected
   which is not a limit case.
7. Otherwise, or if the result of step 6 is not accurate to nearly
   the full precision, the function estimates the cancellation and
   the number of terms of the series in $z$ and in $z/(z-1)$ (each
   also with the parameters $c - a$, $c - b$), of the four connection
   formulas (two series each, with their gamma factors; the limit
   cases at three times the cost per term) and of the corner case,
   evaluates the cheapest one with a working precision that covers
   its cancellation, and compares with the cost of numerical
   integration (`arb_hypgeom_2f1_integration` for real arguments,
   `acb_hypgeom_2f1_integration` for complex ones or if the former
   does not apply; the latter also for $a$, $b$ larger than $c$ and
   $\operatorname{Re} z < 0$, where the Euler integral does not exist
   and the function oscillates). If a result is not accurate, the
   bits which it has lost correct the estimates, and the cheapest
   formula follows. For example ${}_2F_1(1, 1000, 2000, 99/100)$ is
   computed from the series at $z$, whose terms decrease like $2^{-k}$,
   and not from the formula at $1 - z$, whose limit needs 1000 terms;
   ${}_2F_1(5, 5, 12, z)$ at $|1 - z| = 0.45$ from the series at $|z| =
   0.79$ and not from the limit at $1 - z$, which cancels by 21 bits.
   See [](algorithms/special-functions/hypergeometric#choice) and
   [](algorithms/special-functions/hypergeometric#choice-2f1).
8. With inexact input and large parameters, where the error bounds of
   the series are inflated by the cancellation, the function is
   evaluated at the midpoints, and its variation over the input is
   bounded with Cauchy's estimates from a bound for the function on a
   polydisc: from the Euler integral where its integrand is positive,
   from the integral on balls, or from the series with divided
   differences for the first derivatives. If the input is as accurate
   as the working precision, this is attempted as far as it costs no
   more than twice the function on exact input. See
   [](algorithms/special-functions/hypergeometric#inexact).

## Integer parameter differences {#flags}

The transformations to $1/z$ and $1/(1-z)$ divide by $\sin(\pi(b-a))$,
and those to $1-z$ and $1-1/z$ by $\sin(\pi(c-a-b))$, which vanish when
the parameter difference is an integer; the function then computes the
limit (by differentiating with respect to a perturbation of $a$). It
recognizes an integer difference only if it can prove it from the
balls, which works for exact parameters but not, for instance, for $a
= \sqrt 2$ and $c = \sqrt 2 + 3/2$, whose computed difference is an
inexact ball containing $3/2$. The flags `ACB_HYPGEOM_2F1_AB` and
`ACB_HYPGEOM_2F1_ABC` declare that $a - b$ or $a + b - c$ is an exact
integer; the caller is responsible for this being true. The flags
`ACB_HYPGEOM_2F1_AC` and `ACB_HYPGEOM_2F1_BC` are accepted but
currently not used.

## Example {#example}

With $c - a - b = 1$ known only as a ball, the transformation to $1-z$
needed at $z = 0.9$ fails unless the flag is given (the function then
sums the slowly convergent series in $z$, which takes longer than the
limit formula); near $e^{\pi i/3}$
the corner case (method 6) is used; on the branch cut, the value is the
limit from the lower half-plane:

```c example name=acb_hypgeom_2f1_flags
#include <flint/acb.h>
#include <flint/acb_hypgeom.h>

int main(void)
{
    acb_t a, b, c, z, r;

    acb_init(a);
    acb_init(b);
    acb_init(c);
    acb_init(z);
    acb_init(r);

    /* a = sqrt(2) + i/2, b = 1/2, c = a + b + 1: c - a - b = 1 exactly,
       but not as balls */
    acb_set_ui(a, 2);
    acb_sqrt(a, a, 64);
    arb_set_d(acb_imagref(a), 0.5);
    acb_set_d(b, 0.5);
    acb_add_ui(c, a, 1, 64);
    acb_add(c, c, b, 64);
    acb_set_ui(z, 9);
    acb_div_ui(z, z, 10, 64);

    acb_hypgeom_2f1(r, a, b, c, z, 0, 64);
    flint_printf("no flags : "); acb_printn(r, 10, ARB_STR_NO_RADIUS); flint_printf("\n");
    acb_hypgeom_2f1(r, a, b, c, z, ACB_HYPGEOM_2F1_ABC, 64);
    flint_printf("ABC flag : "); acb_printn(r, 15, 0); flint_printf("\n");

    /* near exp(pi i/3) none of the transformations converges well */
    acb_set_d(a, 0.25);
    acb_set_d(b, 1.5);
    acb_set_ui(c, 3);
    acb_set_d_d(z, 0.5, 0.875);
    flint_printf("method   : %d\n", acb_hypgeom_2f1_choose(z));
    acb_hypgeom_2f1(r, a, b, c, z, 0, 64);
    flint_printf("corner   : "); acb_printn(r, 15, 0); flint_printf("\n");

    /* on the branch cut (1, +inf): the limit from the lower half-plane */
    acb_set_ui(z, 3);
    acb_hypgeom_2f1(r, a, b, c, z, 0, 64);
    flint_printf("z = 3    : "); acb_printn(r, 15, 0); flint_printf("\n");

    acb_clear(a);
    acb_clear(b);
    acb_clear(c);
    acb_clear(z);
    acb_clear(r);
    flint_cleanup();
    return 0;
}
```
```output
no flags : 1.457901874 + 0.1101632281*I
ABC flag : [1.45790187393845 +/- 4.63e-15] + [0.110163228098910 +/- 3.65e-16]*I
method   : 6
corner   : [1.01464883732715 +/- 1.68e-15] + [0.134531649059307 +/- 4.66e-16]*I
z = 3    : [0.995480256475680 +/- 1.88e-16] + [-0.581843941733150 +/- 3.70e-16]*I
```

The first call does not use the limit formula: its result comes from
the series in $z$, or from `acb_hypgeom_2f1_integration` where that is
cheaper; this needs $|z| < 1$ or $|z/(z-1)| < 1$ for the series, or
$\operatorname{Re} b \ge 1$ and $\operatorname{Re}(c - b) \ge 1$ (after
exchanging $a$ and $b$ if necessary) for the integral. Where neither
holds, the result without the flag is indeterminate.
